Netlify Drop 公開用ファイル

1. このフォルダをNetlify Drop（https://app.netlify.com/drop）へドラッグ＆ドロップしてください。
2. 公開後に割り当てられたURLをコピーします。
3. index.html内の YOUR-SITE-NAME を、Netlifyのサイト名に置き換えます（og:url、og:image、twitter:image の計4か所）。
4. 更新したindex.htmlをNetlify Dropへもう一度ドロップして反映します。

SNSのOGP画像は og-image.png です。記事内の画像6点は同じフォルダにあり、そのまま読み込まれます。index.md は元原稿として残しています。
